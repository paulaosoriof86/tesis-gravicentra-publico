# Tesis Gravicentra — repositorio público

Repositorio público controlado para materiales de la tesis **Gravicentra / Orbit 360** que hayan sido revisados y autorizados expresamente para exposición en Internet.

## Función de este repositorio
Este repositorio es únicamente la **superficie pública** del proyecto. No sustituye al repositorio maestro privado ni a los documentos acumulativos vivos de la investigación.

Puede contener, según se autorice en cada etapa:
- instrumentos de investigación publicables;
- recursos y micrositios académicos;
- anexos sanitizados;
- visualizaciones con información agregada o anonimizada;
- resultados específicamente aprobados para divulgación;
- materiales de defensa que no comprometan confidencialidad ni propiedad intelectual.

## No debe contener
- borradores completos de la tesis o expediente interno;
- datos personales o respuestas identificables de participantes;
- información real de clientes;
- credenciales, secretos, archivos `.env` o configuraciones privadas;
- código productivo sensible;
- reglas propietarias detalladas o evidencia empresarial confidencial;
- cualquier archivo que no haya superado revisión de publicación.

## Recurso público actual
**Encuesta sobre gestión de seguros — V0.5 publicable.** El código se aloja bajo `docs/encuesta-gestion-seguros/` y se publicará mediante GitHub Pages.

## Gobernanza
Toda publicación relevante debe quedar registrada también en el repositorio maestro privado con versión, commit, URL pública y alcance de lo efectivamente divulgado.

No se concede una licencia general de reutilización por el solo hecho de que este repositorio sea público.
